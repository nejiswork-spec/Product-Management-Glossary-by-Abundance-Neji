# Glossary favicon

Created with the built-in image-generation tool. The source is `glossary-logo.png`. Next.js automatically supplies the icons in `app/favicon.ico`, `app/icon.png`, and `app/apple-icon.png`. Run `node scripts/create-favicons.mjs` to regenerate the size variants.

## Generation prompt

Use case: logo-brand. Asset type: production favicon for Product Management Glossary by Abundance, a clean white documentation website with blue links. Create one premium, distinctive, extremely legible geometric symbol: a single open reference book whose two bold ivory pages subtly form an upward-pointing A in negative space, suggesting knowledge and product direction. Center the bold symbol on a solid deep ink-blue rounded-square tile. Flat two-color vector-like design, carefully balanced optical geometry, generous but not excessive inset, striking at 16 and 32 pixels. Square canvas with tile filling the canvas. No letters, words, small details, gradients, shadows, texture, mockup, border, additional objects or presentation sheet. Deliver the icon alone.
